# 固件附件范围

Release 的原始和修改后 `.bin` 都只是 OSLO 程序镜像，4,259,840 字节。没有发布整机 dump、RBLI / MRD 身份数据、运行配置、原始诊断流或 SIM 数据。

代码和文档的 MIT 许可证不覆盖这些原厂二进制及其内部第三方组件。二进制权利属于各原权利人；本项目不声称拥有其源码，也没有证据把整个原厂固件重新许可为 MIT。公开程序镜像用于本次用户授权的自有设备研究复现。

必须先核对本地原始程序与 bootloader 哈希，再用自己的完整备份生成刷写 / 恢复包。不要将 OSLO 文件当成可直接刷到 Flash 0 地址的整机镜像，不要通过网页升级入口直接上传。

已将公开镜像及解压后的十个程序段与本机已知的 IMEI / IMSI / ICCID / MAC / SN / SSID 进行编码变体匹配检查，未发现命中；整机备份有命中并保持私有。检查边界见 `evidence/privacy-summary.json`。
